🔌 电脑各种接口介绍

看懂这些接口，接显示器、键鼠、网线、硬盘都不会抓瞎。

主板背面接口（机箱后面）
USB-A（2.0 / 3.0）
长方形接口，最常见
接鼠标、键盘、U 盘、移动硬盘、打印机等。3.0（蓝色）比 2.0 传输快很多。
USB-C
椭圆形、不分正反
新设备的通用接口，传数据快、还能给手机/平板充电和接显示器。
HDMI
梯形口，显示器视频线
最通用的接显示器/电视接口，插在显卡上（有独显千万别插主板）。
DisplayPort（DP）
有点像 HDMI 但缺一角
也是接显示器，带宽更高，打游戏高刷新率（144Hz+）优先用 DP。
网线接口（RJ45）
像电话线接口，有卡扣
插网线连宽带，比 WiFi 更稳定、延迟更低，游戏党推荐。
3.5mm 音频接口
小圆孔，通常有绿/粉/蓝
绿色接耳机/音箱，粉色接麦克风，蓝色接音频输入。
WiFi 天线接口
两个金色小圆钮
主板带无线网卡的才有，拧上天线就能连 WiFi 和蓝牙。
显卡接口（机箱后面偏下的位置）
HDMI / DP
显卡的挡板位置
装了独立显卡后，显示器必须接这里，接主板接口会没画面。
机箱前面板接口
USB 口
机箱正面/顶部
临时插 U 盘、手机充电等，使用方便。
耳机/麦克风口
机箱正面小圆孔
插耳机和麦克风，和主板后面的音频口功能一样。
开机键 / 重启键
机箱正面
开机和强制重启。电源灯和硬盘灯会亮起表示通电/读写。
机箱内部接口（装机时会用到）
24pin 主板供电
主板右侧长插槽
电源最大的那根线插这里，给整块主板供电。
8pin CPU 供电
主板左上角
专门给 CPU 供电，别和显卡供电线搞混。
PCIe 显卡供电
显卡顶端
电源的 8pin/16pin 线插这里，给独立显卡供电。
PCIe 插槽
主板中下方长槽
插显卡的位置，通常用最靠近 CPU 的那条（速度最快）。
内存插槽（DIMM）
CPU 旁边的长槽
插内存条。两根内存要插在 2、4 槽（隔开）组双通道。
M.2 插槽
主板上的小长槽
插 M.2 固态硬盘，通常带散热片盖着。
SATA 接口
主板侧边小口
接机械硬盘或 2.5 寸固态，需要电源供电和数据线。
风扇接口（4pin）
主板各处小针脚
插机箱风扇和散热器风扇的线，控制转速。
